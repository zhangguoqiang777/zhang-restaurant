# 小张的餐厅 · 界面原型说明

高保真静态界面稿，只还原视觉与交互状态。不含业务逻辑、不接后端、不含价格 / 支付 / 取餐 / 桌号。

- 入口：`prototype/index.html`
- 样式：`prototype/styles.css`
- 图形：全部内联 SVG（菜品插画 + 图标），无外链 CDN、无外部字体，断网可看
- 桌面多屏并排；≤470px 自动单列并缩放手机外框

## 1. 配色

| 角色 | 取值 | 用途 |
|---|---|---|
| 主色 · 陶土棕 | `#C0603C` | 主按钮、选中态、tabBar 激活、强调标签 |
| 主色深 | `#8E4529` | 主色上的文字、标题强调、深一档按压态 |
| 主色浅 | `#F6E7DD` | 品牌标签底、选中卡片底、进度光环 |
| 页面底色 | `#F4EEE5` | 屏幕背景（奶油暖灰） |
| 卡片 / 纸白 | `#FFFCF7` / `#FFFFFF` | 卡片、导航、tabBar |
| 主文本 | `#3A302A` | 标题、正文 |
| 次文本 | `#6C5C51` | 说明、摘要 |
| 弱文本 | `#9C8B7D` | 时间、辅助信息 |
| 分割线 | `#EADFD2` / `#F3EAE0` | 卡片描边、列表分隔 |
| 待处理 | 字 `#A9741F` / 底 `#FBF1DD` | 仅订单状态 |
| 制作中 | 字 `#8E4529` / 底 `#F6E7DD` | 仅订单状态 |
| 完成 | 字 `#447454` / 底 `#E9F2E9` | 仅订单状态 |

原则：品牌色只有陶土棕一个，奶油底作为中性面；三种状态色只服务于订单语义，不参与普通按钮与装饰。红 `#A5483B` 仅用于取消 / 错误提示。

## 2. 字号层级

| 层级 | 字号 / 行高 | 用途 |
|---|---|---|
| 展示标题 | 28 / 1.25 | 角色选择页主标题 |
| 页面大标题 | 23 / 1.35 | 菜品详情菜名 |
| 区块标题 | 19–20 / 1.3 | 日历月份、采购统计 |
| 导航标题 | 17 / 1.2 | 自定义导航栏 |
| 区块 / 卡片标题 | 15–16 / 1.4 | 菜品名、卡片头 |
| 正文 | 15 / 1.5 | 主内容（对齐小程序 15px 正文） |
| 次要正文 | 13 / 1.55 | 简介、说明段落 |

## 3. 圆角与间距

- 圆角：卡片 14，重点容器 / 图片 18，图片缩略 10–12，按钮与标签 999（胶囊），手机屏幕 37。
- 间距梯度：4 / 6 / 8 / 10 / 12 / 14 / 16 / 20 / 24。
- 屏幕左右安全边距 16；卡片内边距 12–16；卡片纵向间距 8–12；区块之间 14–20。
- 导航 44 + 状态栏 44；tabBar 58 + iPhone 底部安全区 20（原型中合并为 78 高）。

## 4. 视觉规范要点

- 自定义导航栏：标题居中，左侧返回，右侧微信胶囊（87×32），胶囊留白不被内容占用。
- tabBar：4 个等分项，图标 22、文字 10.5；激活项用主色，其余弱文本色。
- 订单状态标签：高度 24、圆角胶囊、11px；三状态只用上表配色，不额外加边框。
- 菜品卡片：横向图片 92×92 + 右侧名称/简介 + 右下角圆形加号；卡片无价格区。
- 菜品图片：内联 SVG 餐盘插画（暖色底、餐盘、主体、点缀、蒸汽），不使用灰色占位块；接入真实数据后替换为 `image_key` 图片，保持 1:1 裁切。
- 层级：所有页面为「状态栏 / 导航 / 内容滚动区 / 底部操作或 tabBar」，内容区独立滚动。
- 按压态：主按钮加深到 `#8E4529`；描边按钮保持底色不变。

## 7. 实现映射提示

- 小程序实现时，`.device/.screen` 外框不需要，只保留状态栏占位、导航、内容区、tabBar。
- 375px 设计宽度对应 iPhone 标准；实际用 `rpx` 时可按 750rpx = 375px 等比换算（1px = 2rpx）。
- 所有交互均为静态展示：按钮、开关、星级为视觉状态，不包含真实提交与接口调用。
- 中英文切换与 AI 推荐本期不实现，原型中不放置语言入口与推荐位。
